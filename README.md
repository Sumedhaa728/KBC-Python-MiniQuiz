# Kaun Banega Crorepati (KBC) – Python Quiz Game

A simple command-line quiz game inspired by the popular Indian television game show **Kaun Banega Crorepati (KBC)**, developed using Python.

The game presents players with multiple-choice questions, where each correct answer takes them closer to winning the grand prize of ₹20,00,000.

## Features

- **Player Identification:** Takes the player's name before starting the game.
- **Multiple-Choice Questions:** Each question has four options (A, B, C, D).
- **Progressive Prize Money:** The prize amount increases with every question.
- **Safe Checkpoints:** Players secure their winnings at specific milestones (₹10,000, ₹1,00,000 and ₹10,00,000).
- **Quit Option:** Players can exit the game at any point and retain their secured winnings.
- **Answer Verification:** Automatically checks the selected answer and determines whether the player can proceed.

## How to Run

**Prerequisite:** Python 3.x installed on your system.

1. Clone this repository:

   ```bash
   git clone kbc_miniquiz.py
   ```

2. Navigate to the project directory:

   ```bash
   cd KBC-Python-MiniQuiz
   ```

3. Run the Python file:

   ```bash
   python kbc_miniquiz.py
   ```

4. Enter your name and enjoy the game!
